<Step title="Install KiCad">
- Download KiCad from [kicad.org/download](https://www.kicad.org/download/)
  and pick your operating system.
- Grab the latest **stable release** (KiCad 10.x) and run the installer - the defaults are fine.
- When prompted, make sure the **default libraries** install (they're
  selected by default). KiCad ships with a large set of schematic symbols,
  PCB footprints, and 3D models covering common components - resistors,
  capacitors, connectors - so you only import specialty parts like the
  XIAO or the OLED.
- Launch KiCad and create a new project (**File → New Project** or
  **Ctrl+N**).
</Step>

## Keybinds you'll live in

The schematic editor is fast once these are muscle memory:

| Key        | Action                                       |
| ---------- | -------------------------------------------- |
| **A**      | Add a symbol (component)                     |
| **W**      | Draw a wire                                  |
| **P**      | Add a power symbol (VCC, GND, 3V3, etc.)     |
| **L**      | Add a net label                              |
| **M**      | Move a component                             |
| **R**      | Rotate a component                           |
| **G**      | Grab/drag a component (keeps wires attached) |
| **E**      | Edit component properties                    |
| **C**      | Copy a component                             |
| **Delete** | Delete selected item                         |
| **Ctrl+Z** | Undo                                         |
| **Ctrl+S** | Save                                         |
