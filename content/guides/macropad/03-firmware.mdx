<Step title="Flash CircuitPython">
- Hold the BOOTSEL button on the Pico while plugging in the USB cable.
  It shows up as a drive called `RPI-RP2`.
- Drag on the CircuitPython UF2 from circuitpython.org. The drive
  reboots and comes back as `CIRCUITPY`.
- That's the whole install - the Pico now runs Python files straight off
  the drive.
</Step>

<Step title="Make it type">
- Copy the KMK firmware folder onto `CIRCUITPY`, then create `code.py`:

```python
import board

from kmk.kmk_keyboard import KMKKeyboard
from kmk.keys import KC
from kmk.scanners import DiodeOrientation

keyboard = KMKKeyboard()
keyboard.row_pins = (board.GP0, board.GP1, board.GP2)
keyboard.col_pins = (board.GP4, board.GP5, board.GP6)
keyboard.diode_orientation = DiodeOrientation.COL2ROW

keyboard.keymap = [
    [KC.A, KC.B, KC.C,
     KC.D, KC.E, KC.F,
     KC.G, KC.H, KC.I]
]

keyboard.go()
```

- Save, open a text editor, and press keys. Letters appear. You built a
  keyboard.
- Swap `KC.A` for macros, media keys, or layers - the KMK docs list
  everything.
</Step>

<Checkpoint>
All nine keys type, in the right positions. If one whole row or column is
dead, that's a pin assignment or a broken trace - not nine broken
switches. Debug the grid, not the keys.
</Checkpoint>
