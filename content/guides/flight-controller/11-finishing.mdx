title: Finishing touches
---

Now I'm going to fix the silkscreen component names so that they look
better (and a bit smaller).

<Step title="Restyle the reference designators">
- Go to `Edit > Text & Graphics Properties`

  ![Text & graphics menu](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_text_graphics_menu.png)

- This window should show up:

  ![Reference designators window](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_reference_designators_window.png)

- Here you're going to select `Reference designators` as this will
  select all of the designators (R1, C1, etc...) on the board so we can
  edit their properties. Then in the action I am going to change the
  font and the size:

  ![Silkscreen font settings](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_silkscreen_font_settings.png)

- You can set these values to whatever you want but I am going to go
  with this. Then click `Apply` to test it out and `Apply and Close`
  when you are done.
</Step>

<Step title="Organize the silkscreen">
- Now all I'm going to do is organize the references like this:

  ![Silkscreen before](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_silkscreen_before.png)
  *(before)*

  ![Silkscreen after](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_silkscreen_after.png)
  *(after)*

- This is completely optional but look at how neat it looks now with all
  the designators/references properly sized and placed:

  ![Silkscreen organized](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_silkscreen_organized.png)

- I even added text to the battery connector to show which side is + and
  -.
</Step>

<Step title="Fix 3D models (optional)">
- If you want to add the 3D models to render, then just go to properties
  and find a 3D model that works for you:

  ![3D model properties](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_3d_model_properties.png)

- (You may have to click on the folder icon next to the path/show button
  to change the 3D model from a `.wrl` to the `.step` in the same
  folder for imported LCSC parts for it to show. Just changing the name
  will not update it.)

  ![3D model before](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_3d_model_before.png)
  *(Before)*

  ![3D model after](https://raw.githubusercontent.com/notaroomba/simpleflightcontroller/main/assets/pcb_3d_model_after.png)
  *(After)*
</Step>

And you're done!
